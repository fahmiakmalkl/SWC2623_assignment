## 📖 Project Overview
This repository contains a prototype for a training centre that analyses learner performance, advises learners on eligible modules, and presents an integrated learning profile. The same problem domain is implemented using three different programming paradigms:
1. **Functional Programming** (Haskell)
2. **Logic Programming** (Prolog)
3. **Multi-Paradigm Programming** (Python)

The three solutions share consistent learner and module data, allowing for a direct comparison of how different paradigms handle the same computational problem.
